show23-pc

This is an unofficial fan project. It is not affiliated with Sony Interactive Entertainment, San Diego Studio, Major League Baseball or the MLB Players Association. Names are used only to identify what the software works with.

Requirements
Windows 10 or 11 x64, a Vulkan-capable GPU, and your own copy of MLB The Show 23 for PS4. Use the 1.00 base game as an unpacked folder, or supply a game package and a supported unpacker of your own.

Set up and play
Extract the entire zip and run show23-pc.exe. Select Set up, choose your game, and pick a separate install folder. The bundled runtime is copied into that install. Select Play to start the game. Saves are in data/profiles/default/user and logs are in data/logs under the install folder.

During play, online card mode uses a local server on your PC. The optional card import is a separate download. Play starts the 1.00 base game in local mode, even when you set up the optional 1.21 update. Version 1.21 is offline-only and this release has no offline launch button.

Cards
Use Import special cards in the launcher to add special cards and their art. This step is optional. Your PC fetches the card list and missing pictures from the publisher's public website. Without the import, only the Live roster with player photos is available. A new player starts with a full squad of Common cards and 5,000 Stubs. Additional cards come from packs, exchanges and programs.
